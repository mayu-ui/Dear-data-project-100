# Dear-data-project-100
Dear Data 100: The Anatomy of a Bug

Project Overview

A #CreativeCoding data visualization project tracking 100 programming errors, bugs, and unexpected visual behaviours encountered during my Computer Science studies at City St George's, University of London.

Data Schema

id (int): Observation number (1–100)

date (String): Date recorded (YYYY-MM-DD)

timeOfDay (String): Session block (Morning, Afternoon, Evening, LateNight)

errorCategory (String): Technical nature of the bug (Syntax, Scope, Type, Visual, Logic, Null)

fixMinutes (int): Time spent debugging in minutes (1–120)

frustration (int): Subjective frustration rating (1–5)

resolution (String): Primary method used to resolve (Self, Docs, Console, Peer, RubberDuck)
